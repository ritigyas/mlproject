Learning hub

Understand regression before you tune it.

Regression is supervised learning for predicting a continuous number: a price, demand, temperature, or—in this example—a mathematics score.

What is regression?

A model learns the relationship between input features (X) and a continuous target (y), then estimates y for unseen records.

Feature engineering

Choose, clean, encode, and scale signals so the model receives useful and consistent inputs.

Generalization

A useful model performs well on new data—not merely on the records it already saw.

Training data fits the pipeline; test data is kept separate for an honest final check. This project uses an 80/20 split with a fixed random state.

High bias is too simple to learn patterns (underfitting). High variance memorizes training noise (overfitting). Cross-validation and tuning help find a useful balance.

R² measures explained variation (higher is better). MAE is average absolute error. MSE squares errors to penalize large misses. RMSE returns MSE to the target's units.

Interview tip

Why not score on training data only?

Because it cannot reveal generalization. A model can show excellent training performance while failing on data it has never seen.
