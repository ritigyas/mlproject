More than a prediction form

This project documents the full learning path: framing a practical problem, preparing data, evaluating models, and serving predictions through Flask.

Project summary

The goal is to estimate a student's mathematics score from demographic context, lunch type, preparation status, reading score, and writing score. It is an approachable real-world regression problem used to apply core ML engineering concepts.

Learning-first, production-minded

Each stage is separated into reusable components—from ingestion and transformation to model training and inference—so the project mirrors a practical machine-learning application.
